# Weekly summary style (default)

Write each project's weekly summary as a timesheet entry:

- One short paragraph of 2-3 sentences, plain prose, no bullet points or headings.
- Say what was done and what it achieved, in the past tense. Leave out commit hashes, file names and tool chatter.
- Base it only on the week's commits and vault notes. Do not invent work.
- If the project has a project number, start the entry with it, e.g. `[P-1234]`.
